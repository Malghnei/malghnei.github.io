## The Problem

Does pizza go with mayonnaise? Sushi? A hot dog? Humanity has wrestled with these questions for centuries. Condimental settles them.

## Features

- Live webcam capture of any food (or anything else)
- AI vision analysis that decides whether it pairs with mayonnaise
- Image generation that shows it with mayonnaise added

## Why

A deliberately silly problem with a serious purpose: a hands-on way to learn how vision and image-generation APIs fit into a real web app.
